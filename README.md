# MeHouse

MeHouse（咪的房）是一款安卓家庭物品管理应用，帮助你记住物品放在哪里、还剩多少，以及什么时候需要处理。

## 功能

- **管理多个家庭**：为不同住所分别记录房间和物品，可切换、创建、重命名或删除家庭。
- **记录存放位置**：按家庭、房间、橱柜和抽屉组织物品；房间布局可调整，并能在网格中查看位置。
- **搜索和分类**：搜索所有家庭中的物品，按到期时间和分类筛选。
- **物品照片**：从手机照片中选择图片，帮助辨认物品。
- **库存管理**：记录消耗品和耐用品的数量与单位；消耗品可设置库存线并补货，耐用品可记录检修计划。
- **到期和待办提醒**：查看临近或已过期物品、低库存物品和检修计划；安卓设备可启用本地通知。
- **本机保存**：安卓数据保存在设备本地，无需注册账号。

## 安装

1. 打开 [GitHub Releases](https://github.com/Echorainy/MeHouse/releases)，进入最新版本。
2. 在该版本的 **Assets** 中下载 `.apk` 文件。
3. 打开下载的 APK 并按系统提示安装。如果安卓提示禁止安装未知应用，请在提示页允许当前使用的浏览器或文件管理器安装应用，然后返回继续安装。
4. 安装完成后，从桌面打开 **MeHouse**。

只从本项目的 GitHub Releases 下载 APK。安装包由项目维护者发布；请在安装前确认发行版来源和版本说明。

## 使用说明

1. **添加物品**：在首页点“记录物品”，填写名称，选择家庭中的房间和存放位置，再选择分类并保存。也可以从房间或网格中添加，应用会带入当前位置。
2. **查找物品**：使用首页搜索可跨家庭查找；在“物品”页可按分类或到期时间筛选。点击列表项目可查看详情或编辑。
3. **管理位置**：在“房间”页新增房间并进入房间布局。可创建橱柜、抽屉等模块，按实际位置整理。
4. **管理库存**：录入时选择消耗品或耐用品。消耗品支持消耗一份、撤销和补货；耐用品可设置检修日期并在检修完成后更新计划。
5. **添加照片**：在物品录入或编辑页面添加图片。首次选择图片时，按安卓提示授予照片访问权限。
6. **启用提醒**：在“设置”页打开提醒通知。安卓系统通知权限可能需要单独允许；拒绝权限后，仍可在应用内查看提醒。

## 数据与更新

物品、房间、家庭和照片保存在当前设备，本应用不提供云同步。卸载应用或清除应用数据可能会删除本机记录；更换设备前请先妥善保留重要信息。

后续更新请从 GitHub Releases 下载新 APK 并安装。请使用由同一项目签名的正式发行包进行覆盖更新；如果系统提示签名不一致，不要先卸载旧版，以免丢失本机数据。

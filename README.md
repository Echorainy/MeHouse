# MeHouse

咪的房 · 家里放哪儿

一个帮助记录家庭物品位置、搜索物品并管理库存、保质期和检修计划的 Expo React Native 应用。

## 运行

```bash
pnpm install
pnpm start
```

数据保存在本机：移动版使用 SQLite，Web 使用浏览器本地存储。没有后端或云同步；清除应用数据或浏览器站点数据会清除记录。

## 库存与提醒

- 记录物品时选择消耗品或耐用品，填写非负整数数量和单位。旧记录默认 1 份，库存类型为“待设置”，可从详情补充。
- 消耗品设置正整数库存线；只有数量低于库存线才提醒。支持消耗一份、5 秒内撤销及补货；补货只增加本条记录，不改变位置或过期日期。
- 耐用品可设置检修日期和提前提醒天数。完成检修后记录完成日期，可选择下一次日期，不自动生成周期。
- 首页依次展示到期、补货、检修提醒；当前家庭各自独立。数量为零保留记录，但不再提醒到期和检修。统计按“条记录”计算。
- 独立移动版授权后使用本地系统通知；Web 和 Expo Go 使用应用内提醒。设置中的“提醒通知”统一管理三类提醒的系统权限。

## 多家庭版本

- 首页点击家名可新建、重命名或切换家。统计和普通物品列表仅查看当前家，搜索覆盖所有家。
- 房间页先显示卡片，点击后进入 8×8 布局。房间、橱柜、抽屉逐级返回。
- 新家从空房间列表开始；首页录入必须选择位置，布局内录入带入当前位置。
- 30 天和 7 天统计都包含今天，排除已过期物品，按本地日历日期计算。

## 验证与浏览器预览

```bash
pnpm test
pnpm typecheck
pnpm exec expo export --platform android --platform web
pnpm exec expo start --web --port 8083
pnpm exec playwright install chromium
pnpm test:ui
```

浏览器打开 http://localhost:8083。浏览器测试覆盖多家庭隔离、全局搜索、位置必选、空家庭、逐级返回、分类管理、午夜到期刷新与三种屏幕宽度的正方形网格。

库存测试覆盖输入校验、严格库存阈值、连续消耗与撤销、补货、检修、旧数据迁移、家庭隔离、通知去重与失败重试，并检查 320、390、1200 px 布局。独立移动版的实际通知展示、权限和后台投递需在真实设备中验证，浏览器测试不能替代。

库存功能不包含小数计量、跨批次自动消耗、库存流水报表、周期检修或云同步。

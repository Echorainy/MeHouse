# 家里放哪儿 · 全局 UI 设计规范

本文档是“家里放哪儿”项目的全局 UI 唯一设计来源。任何页面、组件、交互、视觉改版或猫咪素材生成前，都必须先读取本文档，并在实现后按验收清单检查。

## 定位

“家里放哪儿”App 的轻量陪伴型猫咪助手。形象要圆润、简约、扁平、温暖、友好，并且在手机卡片尺寸下仍然容易识别。

## 造型

- 默认使用单只猫、正面坐姿。
- 身体偏瘦但保持圆润，避免球状或过度肥胖。
- 头部与身体有清晰分界。
- 耳朵较大，使用柔和圆角三角形。
- 尾巴短小，位于身体一侧。
- 脚部只保留简单圆形外轮廓，不绘制脚趾、肉垫或爪子细节。

## 线稿与表情

- 使用粗细一致的暖深棕线稿：`#3D220F`，不用纯黑。
- 外轮廓明显加粗，缩小后仍清晰。
- 眼睛是两条短而粗的圆角竖线或小椭圆。
- 鼻子极小；嘴巴省略，或只保留一条极短线。
- 不使用胡须、睫毛、复杂表情线或纹理线。
- 默认表情温和、安静、友好，略带陪伴感。

## 配色

### 猫咪固定色板

以下颜色构成最后一版猫咪形象，生成猫咪本体时保持不变：

- 主毛色：奶油橘 `#FFD093`
- 暖白区域（口鼻或腹部）：`#FFFAF4
- 耳朵内侧和脸颊：浅粉橘 `#F9B393`
- 轮廓、眼睛和鼻子：暖深棕 `#3D220F`

### App 搭配色

以下颜色只用于 App 界面或猫咪的展示背景，不作为猫咪毛色或线稿颜色：

- App 背景：奶油米白 `#F8F3E9`
- UI 搭配主色：鼠尾草绿 `#708B72`

## 全局 UI 基础令牌

- 页面背景：奶油米白 `#F8F3E9`
- 卡片与输入框表面：暖白 `#FFFAF4`
- 主操作与欢迎区：鼠尾草绿 `#708B72`
- 主要文字与图标：暖深棕 `#3D220F`
- 次要文字：低饱和棕 `#806C58`
- 边框与分隔线：浅暖灰棕 `#E8DCCB`
- 间距：`8 / 12 / 16 / 20 / 24 px`
- 圆角：输入框 `16 px`、统计卡 `18 px`、内容卡 `20 px`、欢迎区 `24 px`

## 页面结构

- 首页：欢迎区、唯一的“记录物品”主操作、全局搜索、到期统计和提醒区域。
- 房间页：温暖房间卡片、8×8 网格预览、房间名称、物品数量和房间操作。
- 物品页：物品总览、筛选范围、物品列表和“记录物品”主操作。
- 设置页：家庭管理、分类标签、到期提醒三个分组卡片。

## 状态颜色

- 家庭物品：柔和暖蜂蜜 `#E7B56F`
- 30 天内过期：浅桃色 `#F4D6C7`
- 7 天内过期：浅鼠尾草绿 `#DDE8DA`
- 已过期：深陶土色 `#C27454`
- 正常状态使用鼠尾草绿，即将到期使用蜂蜜或浅桃色，过期使用陶土色；不同状态不得复用同一语义颜色。

## 组件规范

- 欢迎区使用鼠尾草绿背景、24 px 圆角，家庭名称和问候语使用暖白文字，猫咪位于右侧且不改变文字布局。
- 搜索框使用暖白表面、16 px 圆角、48 px 左右高度，保留搜索图标和现有无障碍标签。
- 统计卡使用两列稳定布局、18 px 圆角和固定高度，文字使用暖深棕并保持语义颜色区分。
- 内容卡与物品列表行使用暖白表面、浅暖边框和 16–20 px 圆角；长名称允许收缩或单行截断。
- 筛选 Chip 保持可点击尺寸、选中态边框和浅绿色背景，不改动现有筛选逻辑。
- 主按钮使用鼠尾草绿背景、暖白文字、16 px 圆角和 48–52 px 高度；每个页面最多一个高强调主按钮。
- 次按钮使用浅绿色背景和鼠尾草绿文字。
- 设置行保持至少 52 px 高度，文本区可收缩，编辑和删除操作固定在右侧。
- 空状态保留猫咪陪伴插画、标题和说明文字，避免复杂装饰。
- 底部导航使用暖白背景、浅暖边框和稳定触控高度。

## 交互与可访问性

- 保持现有 `accessibilityRole`、`accessibilityLabel`、选中状态和键盘可操作性。
- 卡片、列表行和按钮保持稳定点击区域，窄屏下不得因文字溢出导致布局跳动。
- 删除、清空等破坏性操作必须继续使用确认弹窗。
- 视觉改版不得改变领域数据、持久化格式、通知逻辑、搜索范围、筛选逻辑或导航回调。

## 响应式与验收

- 在 320 px、390 px 和 1200 px 宽度下检查无重叠、裁切和横向溢出。
- 统计颜色不能重复表达不同状态；文字与背景必须保持清晰对比。
- 猫咪缩小到首页卡片尺寸后，轮廓、眼睛和耳朵仍清晰可辨。
- 首页、房间页、物品页和设置页必须继续显示正确数据，并保持搜索、筛选、点击、编辑、删除、新增和通知操作正常。

## App 首页视觉规范

首页采用“温暖欢迎区 + 重点统计 + 到期概览”的信息层级，整体保持轻量陪伴感，让猫咪和颜色提供情绪，而不抢夺物品信息的注意力。

### 页面基础令牌

- 页面背景：奶油米白 `#F8F3E9`
- 卡片与输入框表面：暖白 `#FFFAF4`
- 主操作与欢迎区：鼠尾草绿 `#708B72`
- 主要文字、图标和分隔线强调：暖深棕 `#3D220F`
- 次要文字：低饱和棕 `#806C58`
- 边框：浅暖灰棕 `#E8DCCB`
- 统一间距：`8 / 12 / 16 / 20 / 24 px`
- 统一圆角：输入框 `16 px`、统计卡片 `18 px`、内容卡片 `20 px`、欢迎区 `24 px`

### 欢迎区

- 使用整块鼠尾草绿背景，圆角 `24 px`，移动端最小高度约 `214 px`。
- 家庭名称位于左上方，使用暖白粗体；右侧保留家庭切换入口。
- 主问候语为“今天也要把家照顾好”，使用暖白大字号，允许在窄屏自然换行。
- 辅助文案使用浅绿色白色 `#E6EEE4`，保持低对比度陪伴感。
- 猫咪位于欢迎区右侧，使用透明背景占位或最终 PNG，显示比例固定，不改变文字布局。

### 到期统计卡语义配色

四张统计卡必须使用不同语义颜色，禁止“30 天内过期”和“已过期”使用同一颜色：

- 家庭物品：柔和暖蜂蜜 `#E7B56F`，用于总量和日常状态，避免过深造成突兀。
- 30 天内过期：浅桃色 `#F4D6C7`，表示需要关注但不紧急。
- 7 天内过期：浅鼠尾草绿 `#DDE8DA`，表示近期可安排处理。
- 已过期：深陶土色 `#C27454`，表示明确需要处理的异常状态。

统计卡文字统一使用暖深棕；卡片保持稳定高度和两列布局，在窄屏不发生文字溢出。

### 到期概览

- 标题使用“到期概览”，与统计区保持 `24 px` 左右的视觉间距。
- 每条物品使用独立暖白卡片，圆角 `16 px`、浅暖边框和稳定行高。
- 状态点与右侧状态文字使用语义色：过期使用陶土色，即将到期使用蜂蜜色，正常使用鼠尾草绿。
- 物品名称使用暖深棕粗体；路径、日期和分类使用低饱和棕次要文字。

### 主操作

- “记录物品”是首页唯一高强调主按钮。
- 使用鼠尾草绿背景、暖白文字、圆角 `16 px`，保持稳定高度 `48–52 px`。
- 不在统计卡或到期列表中加入同等强度的第二主按钮。

猫咪只使用上述固定色板中的扁平纯色块，不使用渐变、复杂阴影、写实毛发或高饱和蓝紫色。生成时不得用鼠尾草绿替代猫咪主毛色，也不得用奶油米白替代透明背景。

## 生成规格

- 优先输出透明背景 PNG，尺寸 1024 × 1024。
- 居中构图，保留足够留白。
- 适用于首页欢迎区、空状态、搜索无结果、记录成功和到期提醒。
- 所有变体必须保持相同的头身比例、耳朵形状、线稿粗细、主色和极简程度。

## 禁止事项

- 过胖的球形身体或头身完全粘连
- 过小、尖锐或不对称的耳朵
- 复杂嘴巴、脚趾、肉垫、爪子或脸部纹理
- 细而断裂的线稿
- 多只猫、表情包网格、文字、水印或品牌标志
- 模仿参考图中的具体角色、构图或版权元素

## 使用规则

每次生成或修改猫咪图像前，先阅读本文件，并在提示词中保留“造型、线稿、配色、禁止事项”四部分约束。生成后检查透明背景、轮廓粗细、眼睛粗细、耳朵比例和手机小尺寸可读性。

## 库存、补货与检修（2026-09-28）

- 首页顺序：欢迎区、唯一主按钮“记录物品”、搜索、到期提醒、补货提醒、检修提醒。搜索时只显示搜索结果和记录入口。
- 首页到期统计卡只显示标题和数字，不显示“条记录”尾注；计数仍按物品记录统计。
- 物品页和房间页的物品信息、消耗和补货操作放在同一张卡片边框内，沿用首页卡片的次按钮样式。
- 数量按非负整数和单位展示；统计始终按“条记录”计数。库存类型与分类标签独立。
- 物品页不提供库存类型筛选；消耗品可消耗一份或补货，耐用品可完成检修。
- 补货条件严格为数量低于库存线；零库存显示“已用完”，不删除记录，不显示到期和检修待办。
- 提醒卡沿用暖白表面、浅暖边框、20 px 圆角。低库存和临近检修使用蜂蜜色提示，已用完和逾期检修使用陶土色，并配文字。
- 卡片操作使用次按钮，至少 48 px 高，窄屏允许换行；物品详情点击区域与操作按钮分开，避免嵌套按钮。
- 首页欢迎区的家庭切换与问候语编辑使用独立点击区域；保留背景长按／右键编辑，不嵌套按钮。
- 消耗后提供 5 秒撤销入口，撤销仅返还本次的一份。补货弹窗说明当前记录共享位置与过期日期。完成检修需确认，可选择下一次日期。
- 录入表单增加类型、数量、单位和对应提醒配置；保留现有位置、分类和保质期功能。
- 设置页统一称“提醒通知”；系统权限适用于到期、补货、检修，Web／Expo Go 显示应用内提醒。
- 旧记录数量为 1、单位为份、类型待设置；本次功能变更允许增加库存数据和通知逻辑，不改变既有网格和分类行为。

## 物品页筛选布局（2026-09-28）

- 物品页不显示“家里的物品”栏；记录数放在页面标题下方，与家庭名称同一行靠右显示。筛选和列表直接放在页面背景上，不使用包围整页内容的外层卡片。
- 过期时间与物品分类使用独立可折叠筛选组，过期时间默认展开、分类默认收起；两个展开箭头左侧文字统一固定为“全部分类”，收起不清空筛选，选中条件通过展开后的标签状态展示。
- 只保留过期时间和物品分类筛选；一级分类切换时清空二级分类，筛选条件组合生效。
- 折叠标题点击区域至少 48 px，提供展开状态与无障碍标签；标签自然换行，沿用现有选中态。
